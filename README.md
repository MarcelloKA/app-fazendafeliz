# 🐄 App Fazenda | Gestão Inteligente de Gado

**Uma solução mobile desenvolvida para modernizar e facilitar o gerenciamento de propriedades rurais e rebanhos bovinos.**

O App Fazenda é um projeto acadêmico desenvolvido em equipe, com foco na digitalização de processos de gestão pecuária. A aplicação permite centralizar informações dos animais, acompanhar seu histórico e facilitar o controle das atividades da propriedade em um único ambiente.

O projeto foi desenvolvido utilizando tecnologias modernas de desenvolvimento mobile e integração com serviços em nuvem.

## 🚀 Funcionalidades

- **Cadastro de animais:** registro e gerenciamento dos animais do rebanho.
- **Controle de inseminação:** acompanhamento dos registros de inseminação.
- **Histórico de saúde:** organização de informações sobre vacinação, pesagem e saúde dos animais.
- **Painel de gerenciamento:** visualização de indicadores e informações gerais do rebanho.
- **Anotações:** registro de observações importantes para o gerenciamento da propriedade.
- **Armazenamento em nuvem:** integração com Firebase para autenticação e persistência de dados.

## ⚙️ Como executar o projeto

**1. Clone o repositório:**

```bash
git clone https://github.com/MarcelloKA/app-fazendafeliz.git
```

**2. Entre na pasta:**

```bash
cd app-fazenda
```

**3. Instale as dependências:**

```bash
npm install
```

**4. Configure o Firebase:**

Configure as credenciais e os serviços do Firebase necessários para o funcionamento da aplicação.

**5. Inicie o ambiente Expo:**

```bash
npx expo start
```

Utilize o Expo Go ou um emulador compatível para executar o aplicativo.
